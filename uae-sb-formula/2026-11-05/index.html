0. 공식 — 무엇을 맞추면 흑자인가

SB ROAS = 구매율 × 객단가 ÷ 클릭당 비용  ·  본전 세럼 1.98 · 크림 1.99

객단가는 거의 판매가(주문 대부분이 1개)라 두 제품 다 AED 99일 때 흑자 조건 = 클릭당 비용 ≤ 구매율 × 50. 숫자로 보면 아래 표다.

3. 3단계 — 두 제품을 같은 자로 잰다

Phase A 11/5 ~ 11/18 · 세럼 134·재고 81 · 추가 광고비 0 — 크림 본선 + 세럼 준비

  • 크림: 3축(눈가 주름·보습·발견망) 유지 + 눈가 주름 입찰 +20% 1건(ROAS 2.13, 예산 100 중 18.6만 사용). 창 11/5~18 → 판정 11/25: 3축 합산 ROAS 1.5 이상·하루 주문 1.2 이상이면 유지하고 눈가 한 번 더 상향, 1.0 아래면 크림 SB 예산 절반 → SP.
  • 세럼: 새 돈 0. 목 축('serum' 구절, AED 25/일)은 그대로 둔다 — 134 가격에서 같은 키워드 구매율을 공짜로 재는 대조군. 나머지 3축(기미·눈가·여드름: 14일 AED 95·주문 1)은 11/10 판정 때 접기 기본안. ※ 오전 보고의 "세럼 축 4개 접기"는 목 축 제외로 고침.
  • 준비(광고비 0): ① 검색어 원장(SB 보고서 429 풀리면 재시도 + SP 60일) → 제품별 '팔린 검색어' 목록 ② 정밀 키워드 세트 확정(아래) ③ 입찰 역산(가정 구매율 4% → 상한 2.0, 시작 1.6) ④ 축캠과 겹치는 키워드는 정밀캠 가동일에 축캠 쪽 정지(키워드 쪼개 물기 금지).

Phase B 세럼 입고 확인 + 99 복귀일(예상 11/19) ~ 12/7 · 학습비 AED 1,900 — 정밀 SB 두 제품 동시

  • 신설 2캠: AE_sb_serum_precision(AED 60/일) · AE_sb_cream_precision(AED 40/일). 광고그룹 3개 = 셀 3개. 영상 2개 고정. 입찰 시작 1.6·상한 2.0. 배치 가중 0.
  • 기간 안에 화이트 프라이데이(11/20~12/1 추정, 날짜 미공개)가 들어온다 → 딜 날 / 평일 분리 판정. 피하지 않는다 — 12월까지 딜 없는 깨끗한 2주가 없다.
  • 판정 12/14(창 12/7 + 7일), 셀별·체제별: 평일 구매율 4%+ & ROAS 1.6+(클릭 100+) → 공식 후보 / 2~4% → 발견 캠페인으로 강등(입찰 1.0) / 2% 미만 → 정지. 딜 날은 ROAS 2.5+여야 후보. 클릭 100 미만 셀은 보류·2주 연장.
  • 학습비: 세럼 60×19 + 크림 40×19 = AED 1,900(₩75만). ROAS 1.2로 끝나면 손실 약 AED 750(₩30만), 공식이 맞으면 0. 세럼 추가 판매는 하루 1개 안팎(30클릭 × 4%) — 항공 480 입고 전제.
  • 기대 숫자(가설, 틀리면 틀린 대로 기록): 세럼 S-a 구매율 4~5%·ROAS 1.8~2.3 / S-b 2~3% / S-c 5%+(표본 작음) · 크림 C-a 3~4% / C-b 5% / C-c 3%.

Phase C 12/8 ~ 12/31 · 베스트딜 12/8~20·12/23~28 · 학습비 ~AED 2,500 — 입찰 공식 적용 + 발견망 재편

  • 공식 후보 셀: 입찰 = 측정 구매율 × 99 ÷ 2.0(5% → 2.48 · 4% → 1.99 · 3% → 1.49). 조정은 2주 1회, ±20% 안.
  • 발견 캠페인: 제품당 1개, 입찰 AED 1.0(본전 CPC 1.07 아래), 넓은 일치 허용 — 새 키워드를 우연히 찾는 유일한 장치. 11/4 정지한 세럼 발견망을 1.0으로 재가동, 크림 발견망 1.94 → 1.0.
  • 2주마다 SP·SB 검색어 원장에서 반복 전환어를 정밀캠 정확으로 이식.
  • 판정 1/7(창 12/31 + 7일): 제품별 정밀캠 14일 ROAS 본전 이상 → 공식 확정, 1월 예산 2배 / 1.2~본전 → 2주 더 / 1.2 미만 → 그 제품 SB는 발견망만 남기고 SP로.

5. 세럼 재고와의 관계

Phase A는 세럼 새 돈 0이라 11/4 '134로 늦추기' 결정과 충돌하지 않는다. Phase B는 입고(항공 480, 11/18 전후) 확인 + 쿠폰·99 복귀가 시작 조건이다 — 날짜가 아니라 조건. 입고가 늦으면 B가 밀리고 C도 같이 민다(창 길이는 유지).

6. 못 당기는 레버 — 객단가(번들·스토어)

UAE는 번들이 막혀 있다MENA 브랜드 레지스트리 미등록(UAE 상표 출원 7/24 보류)이라 Virtual Bundle·브랜드 스토어 생성이 차단돼 있다. 세럼+크림 번들(약 AED 180)이 있으면 같은 클릭당 비용에서 필요한 구매율이 4% → 2.2%로 절반이 된다. 7/24 결정의 재검토 조건은 "UAE 매출이 커져 번들이 우선순위에 오를 때" — 지금이 그때인지는 John·Marco 판단(리드타임 수개월). 이 설계는 번들 없이도 성립하는 공식을 찾는다.

7. 한계 — 미리 적어 두는 것

  • SB 검색어 보고서가 11/5 오전 429로 막혀 세럼 검색어 원장은 10/25~31 1주치뿐 — Phase A 준비에서 보강.
  • 세럼 'serum' 구절 구매율 5.2%는 96클릭·5주문 — 95% 신뢰구간 약 1.7~11.7%. Phase B가 이걸 재는 실험이다.
  • 화이트 프라이데이 날짜 미공개 — 체제 분리는 실제 딜 배지 날짜로 사후 태그.
  • 딜 날·평일 분리는 표본을 더 쪼갠다 → 셀 수를 제품당 3개로 제한했다.
